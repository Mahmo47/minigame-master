# Game Rules – Infinite Memory

- Each wave starts with **5 pairs / 10 cards**.
- The board uses **5 columns × 2 rows**.
- When a pair is matched, those two cards fade out and disappear from the active board.
- The remaining cards keep their positions; the board does not shuffle during the wave.
- When all 5 pairs have disappeared and Focus is still above 0%, a fresh wave of 5 new pairs is generated automatically.
- The run ends only when Focus reaches 0% or when the player ends the run manually.

## Scoring
- correct pair: `220 + combo × 80`
- wrong pair: `-30 points`
- remaining time gives **no points**

## Focus system
- wrong pair: `-12%`
- second-card decision window expires: `-7%`
- correct pair: `+3%`

## Difficulty
Every 5 minutes the difficulty increases by 10%.
