# V5 changes

- Start wave reduced to **5 pairs / 10 cards**.
- Infinite behavior changed to wave-based refill: matched pairs disappear; after all 5 pairs are gone, a new wave appears if Focus > 0%.
- Card back replaced by an exact crop from the approved reference and rendered with safe margins so the right border is no longer cut off.
- Card faces now use only consistent high-quality 3D object cards from the approved reference.
- Card size set to 190×190 for a closer match to the reference.
- Remaining cards keep their board positions after a match.
- Vertical spacing/margins reduced so the footer stays visible and the whole game fits inside the window.
