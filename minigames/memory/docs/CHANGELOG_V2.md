# Changes in this package

- Infinite mode now works in waves: matched pairs disappear; when the full board is cleared and focus is above 0%, a fresh set of pairs is spawned.
- Card back alignment moved further left to avoid right-side clipping.
- Board layout updated to a 6 × 4 card format to better match the reference image.
- Card size increased for a closer match to the requested mockup.
- UI remains in English and keeps the focus system.
