# Memory Match — Godot 4

A polished English memory game with a bright professional interface and neutral card images.

## Features
- Large, resizable window that starts maximized
- Bright light theme
- Easy: 6 pairs / 12 cards
- Medium: 10 pairs / 20 cards
- Hard: 15 pairs / 30 cards
- Separate high score and best time for each difficulty
- Time, moves, pairs, and live score counters
- Replaceable PNG, JPG, and JPEG card images

## Start
1. Extract the ZIP file.
2. In Godot 4.7.1, click Import.
3. Select `project.godot`.
4. Open the project and press F6 or F5.

## Replace card images
Click **Open Card Folder** in the game. Replace the files with your own PNG/JPG/JPEG images, then click **Reload Images**. Keep at least 15 different images for Hard mode.

High scores are saved in `user://memory_highscores.cfg`.
